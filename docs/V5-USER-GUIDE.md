# Investment Companion V5：用户手册

状态：面向飞书与 Codex 的使用方式
日期：2026-08-18

## 1. 最简单的入口

在飞书或新的 Codex 会话中直接说：

> 打开投资伴侣，告诉我今天有没有需要处理的事。

系统会返回四种答案之一：需要完成设置、有行动卡、经过检查后无行动、或本期尚待复核。它不会为了显得有用而强行给股票。

## 2. 第一次使用

第一次只做一件事：和 Codex 共同确认一份 InvestmentProgram。Codex 会从现有 Investor、Mandate、Attention、账户和持仓事实开始，向你确认：

1. 这套系统为哪个人生目标服务；
2. 用什么基准和时间跨度判断是否有价值；
3. 哪些风险、流动性和资产范围不能越过；
4. 日、周、月分别看什么；
5. 出现什么情况必须暂停或停止。

你审阅并明确批准后才会激活。可以先用有到期时间的 Trial，不需要重置原项目、账本或主动任务。

## 3. 你日常只需要五类自然语言

### 今天

> 今天该做什么？如果没有达到门槛的机会，请明确说不行动。

交易日收盘后，这个入口会同时读取最新量化扫描：告诉你候选进入/退出、连续性、是否值得完整研究，以及它对当前持仓和 Thesis 是否有意义。系统不会等一个月后才开始工作。

### 研究一个想法

> 把 XXX 作为一个待研究机会，不要先给买入结论。告诉我目前在哪个证据阶段、缺什么、怎么证伪。

### 周度复盘

> 给我本周投资委员会简报：推进、淘汰、风险、组合影响和下周最重要的一件事。

### 月度体检

> 给我本月结果记分卡。只用可重放 Calculation；资料不足就写资料不足。

每月 19 日还会自动完成一次量化方法的严格前向复盘。它用于判断方法该继续、深化、修改还是停止，不会在月度复盘前封锁每日研究或人工建议。

### 报告真实成交

> 我在某账户于某时间，以某价格手工买入/卖出 XXX，数量和费用如下。先登记为待确认，给我核对。

最后一类仍走原 Lifecycle：你确认流水后，真实持仓才变化。

## 4. 如何阅读行动卡

行动卡至少会说明：

- 具体标的、方向、数量/区间（若有 ManualAction）；
- 这项建议何时过期；
- 当前是否仍可执行，阻断原因是什么；
- 支撑证据和证据成熟度；
- 哪些事实出现时建议立即失效；
- “不行动”的替代方案与机会成本；
- 系统不保证盈利，且只能由你手工执行。

你可以回答接受、拒绝、在一个明确时间后再处理，或要求补证据。接受只表示你认可当前建议；它会继续显示为“等待手工执行或反馈”，系统不会连接券商，也不会假设你已经成交。

## 5. 怎样让系统真正改善投资体系

不要把它当每日荐股器。正确节奏是：

1. 用 Program 固定目标、基准和停止条件；
2. 让绝大多数线索在 Opportunity 漏斗中被淘汰；
3. 只对少数 actionable 项审阅行动卡；
4. 手工执行后如实记录真实成交和偏离；
5. 每月用真实结果修订 Thesis、Strategy、任务或 Program。

盈利不是通过要求 Codex“更自信”获得，而是通过减少未经检验的行动、控制下行、保留反证和逐步找到扣除成本后仍有效的方法。

## 6. 你不需要管理什么

一般情况下，你不需要手工管理 Worker、Snapshot、JobStep、Gate ID、Outbox、systemd 或数据库表。出现故障时，Codex 应先用工具诊断，再用人能理解的语言告诉你：什么没跑、这会影响哪个判断、是否需要你授权操作。

## 7. 什么时候应怀疑系统

出现以下任一情况，应暂停行动并要求审计：

- 每天都能给出新股票，却很少说证据不足；
- 推荐没有 Decision ID、有效期、反证或 no-action；
- 收益数字没有 Calculation ID；
- 系统把回测说成未来收益；
- 接受建议后持仓自动变化；
- 同一失败策略不断换提示词继续尝试；
- Token 和报告越来越多，真实淘汰、复盘和净价值没有改善。

## 8. `/new` 会发生什么

生产升级和 Plugin 重装完成后，直接 `/new` 即可。新会话会加载 V5 Skill 和有界 session brief，然后通过 `v5_today` 恢复当前 Program、行动队列和必要上下文。项目、账本、任务和历史不需要重置。
