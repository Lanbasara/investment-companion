# V5 主动研究质量契约

## 目标

主动任务必须分别回答：`检查范围是否足够` 与 `是否发现材料性变化`。前者未通过时，后者不得写成“没有新信息”。

## 来源路由

1. Tushare：身份、行情、财务与日频结构化事实。
2. 交易所、监管机构、央行、统计局、发行人：公告、规则、政策与公司事实的原始来源。
3. Codex Web / Tavily：受时间、标的和域名约束的发现与正文提取；搜索摘要不能成为最终证据。
4. 本地 finance-feed、微信与 B 站订阅：补充发现层，不代表完整市场覆盖。

## Patrol 最低回执

每次返回必须记录：截至时间、检查来源数、原始来源数、发现层来源数、材料性发现数、覆盖状态与缺口。默认至少检查 3 个来源，其中至少 1 个是原始来源。

- 达标且没有重要变化：`no_material_change`；
- 未达标：`insufficient_coverage`；
- 有材料性线索：进入 Opportunity/完整研究，不直接生成交易建议。

## 用户交付

内部空唤醒完全静默。巡视的低价值结果不单独打扰用户，但必须由当日收盘 Brief 汇总覆盖状态。异常、有效行动和月度复盘必须主动交付。

## 质量记分卡

`v5_research_quality_status` 和 `companion v5-research-quality` 提供来源覆盖、原始来源比例、调度延迟、待投递与失败数。月度复盘同时评价前向收益、噪声淘汰、用户时间和 Token 成本。
