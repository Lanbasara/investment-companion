02

一次主动工作的完整循环

事件描述世界发生了什么，不预先规定 Codex 必须做什么。

  1. 感知定时巡视、数据变化、文件或用户输入形成事件
  2. 恢复按主题加载最少必要的事实、Thesis 与未决问题
  3. 调查按需调用结构化数据、Web 和短命专业 Agent
  4. 判断增量更新认知，并由确定性内核完成组合计算
  5. 治理根据重要性、预算、冷却和偏好决定通知或静默
  6. 延续保存结果、审计理由与下一观察条件
03

从这里使用

不用管理数据库或定时器，直接在飞书里说出意图。

管理主动性

“现在观察什么？”

列出 Schedule、Watch、最近触发及下一运行时间，并可自然语言启停或修改。

维护真实组合

“记录这笔成交”

先生成 Draft，经确认后进入只追加账本；未确认信息绝不改变持仓。

专业研究

“分析这个标的”

使用结构化市场数据、官方材料和独立反证审查，报告来源、口径和分歧。

长期决策

“我应该调仓吗？”

恢复个人目标、约束、组合与 Thesis，用精确计算评估选择和机会成本。
